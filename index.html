LLM Evaluation & Regression Pipeline

prompt-eval-pipeline
PythonPydanticAnthropic & OpenAI APIspytestGitHub ActionsDocker

Problem

Prompt changes can silently break an LLM feature, and "looks fine" isn't a release criterion.

Approach

Every prompt change runs against a 60-case human-curated golden dataset, including ambiguous, typo, multilingual, sarcasm, and multi-intent stress cases, scored by exact match and LLM-as-judge rubrics.

Result

CI gates warn at a 3-point accuracy drop and block merges at 8 points overall or 10 points in any category, with HTML diff reports, PR comments, and Slack alerts.

Prompt change (PR)→ Run golden dataset→ Score + LLM judge→ Diff vs. baseline→ Pass / warn / block

AI Pipeline Forensics

ai-pipeline-forensics
PythonFastAPIStreamlitSQLiteDocker Compose

Problem

Multi-step LLM pipelines fail silently: one step returns a confident wrong answer while every step reports success.

Approach

Step-level tracing of a 4-stage document pipeline, then a backward root-cause analyzer that walks failed runs to the step that introduced the error.

Result

A 7-category failure taxonomy, adversarial test documents, and confirmed failures turned automatically into permanent regression tests tracked on a dashboard.

LLM Cost Autopilot

llm-cost-autopilot
Pythonscikit-learnFastAPIStreamlitSQLiteDocker

Problem

Sending every request to the most capable model is expensive; most prompts don't need it.

Approach

A classifier (lexical features + TF-IDF) routes each prompt to the cheapest capable model across 3 Claude/GPT tiers in under 5ms; a background verifier checks quality against a top-tier baseline and escalates when it drops.

Result

59% lower API cost than an all-top-tier baseline on 300 seeded synthetic requests, with every decision logged and shown on a live KPI dashboard.

Request→ Classifier (<5ms)→ Cheapest capable tier→ Response+ Async quality check → escalate

Results are from simulated traffic, not production.
